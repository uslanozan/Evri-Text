# Güvenlik politikası

## Desteklenen sürümler

Proje `0.x` geliştirme dönemindeyken yalnızca en güncel sürüm için güvenlik
düzeltmeleri hazırlanır.

## Güvenlik açığı bildirme

Bir API anahtarının açığa çıkması, yetkisiz veri erişimi veya benzeri bir güvenlik
sorunu bulursanız herkese açık issue açmayın. Depo yayımlandıktan sonra GitHub'ın
**Private vulnerability reporting** özelliğini kullanın.

Rapora açığın etkisini, yeniden üretme adımlarını ve mümkünse önerilen düzeltmeyi
ekleyin. Gerçek API anahtarlarını, eşleştirme tokenlarını veya kişisel cihaz loglarını
rapora koymayın.
