# Üçüncü taraf bildirimleri

Evri Text aşağıdaki açık kaynak bileşenleri doğrudan veya geçişli olarak kullanır.
Kesin sürümler `gradle/libs.versions.toml` ve Gradle bağımlılık ağacında tanımlıdır.

| Bileşen | Lisans |
| --- | --- |
| AndroidX kitaplıkları | Apache-2.0 |
| Material Components for Android | Apache-2.0 |
| Kotlin Standard Library | Apache-2.0 |
| kotlinx.coroutines | Apache-2.0 |
| kotlinx.serialization | Apache-2.0 |
| OkHttp ve Okio | Apache-2.0 |
| NewPipeExtractor | GPL-3.0-or-later |
| TeamNewPipe nanojson | Apache-2.0 |
| jsoup | MIT |
| JSR-305 annotations | Apache-2.0 |
| Protocol Buffers Java Lite | BSD-3-Clause |
| Mozilla Rhino ve Rhino Engine | MPL-2.0 |
| desugar_jdk_libs | GPL-2.0-only WITH Classpath-exception-2.0 |

Kaynak ve lisans metinleri:

- [AndroidX](https://github.com/androidx/androidx)
- [Material Components](https://github.com/material-components/material-components-android)
- [Kotlin](https://github.com/JetBrains/kotlin)
- [kotlinx.coroutines](https://github.com/Kotlin/kotlinx.coroutines)
- [kotlinx.serialization](https://github.com/Kotlin/kotlinx.serialization)
- [OkHttp / Okio](https://github.com/square/okhttp)
- [NewPipeExtractor](https://github.com/TeamNewPipe/NewPipeExtractor)
- [TeamNewPipe nanojson](https://github.com/TeamNewPipe/nanojson)
- [jsoup](https://jsoup.org/license)
- [JSR-305](https://github.com/findbugsproject/findbugs)
- [Protocol Buffers](https://github.com/protocolbuffers/protobuf)
- [Mozilla Rhino](https://github.com/mozilla/rhino)
- [desugar_jdk_libs](https://github.com/google/desugar_jdk_libs)

Bu dosya kolay başvuru içindir; her bileşenin dağıtımına eşlik eden lisans metni ve
telif bildirimi geçerlidir.
